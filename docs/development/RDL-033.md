# RDL-033 - Specialist Detail Code Retirement & Simplification

## Objective

Retire the duplicate CFIHOS specialist entity-detail implementations after RDL-032 made the release-aware generic entity detail the canonical runtime model.

RDL-033 is a non-functional simplification sprint. Existing browse/list entry points remain available, legacy detail URLs remain compatible, and all detail rendering continues through the canonical `/rdl/:sourceKey/:releaseKey/:entityType/:nativeIdentifier` architecture.

## RDL-033.1 - Browse-page retirement foundation

RDL-033.1 removed route-param-driven specialist detail logic from:

- Tag Classes
- Equipment Classes
- Document Types
- Data Dictionary / Properties
- Source Standards
- Disciplines
- Units of Measure

The pages remain browse/search surfaces. Selecting an entity still navigates to the existing legacy compatibility URL, which RDL-032 immediately redirects to the explicitly pinned CFIHOS 2.0 canonical detail route.

RDL-033.1 also simplified `RdlScopedLegacyGuard` so it is a browse/scope guard only. The retired `detailParam`, route-parameter lookup and intermediate generic-detail card are removed.

The seven retained browse modules total 1,654 TypeScript lines.

## RDL-033.2 - CSS and residual asset cleanup

RDL-033.2 removes page-local CSS that was only reachable from the specialist detail implementations retired in RDL-033.1.

The cleanup is usage-proven rather than name-based. Every class retained in the seven specialist browse stylesheets must still be referenced by current TSX source. The deterministic RDL-033 contract fails if a retired detail selector is reintroduced or an orphan page-local CSS class remains.

The seven stylesheets fall from 7,147 lines to 1,965 lines while preserving the browse/list presentation and responsive layouts.

Removed residual styling includes, where applicable:

- specialist property and relationship drawers;
- specialist detail headers, cards and metadata grids;
- specialist required-document tables;
- JIP33 detail presentation owned by the retired Tag detail implementation;
- specialist Source Standard property/picklist tables;
- specialist Discipline relationship tables;
- retired Units-of-Measure detail rows/cards;
- obsolete detail-only animation keyframes.

The `uom-detail` browse layout container remains because it is still used by the current Units browse page; only its retired nested detail styling is removed.

## Preserved behavior

- `/classes/tag`, `/classes/equipment`, `/documents`, `/dictionary`, `/standards`, `/disciplines`, and `/units` remain browse routes.
- Search/filter behavior on those pages remains in place.
- The seven legacy detail URL families remain registered through `RdlLegacyEntityRedirect`.
- CFIHOS compatibility redirects remain explicitly pinned to `cfihos` / `cfihos-2.0`.
- Non-CFIHOS browse scope remains release-isolated and fail-closed.
- RDL-030, RDL-031 and RDL-032 contracts remain mandatory.
- Search and relationship runtime artifacts are not changed.

## Removed behavior / assets

The browse-page modules and their stylesheets no longer maintain a parallel specialist detail system. Specifically they no longer:

- read detail route parameters;
- load specialist detail repositories in response to a route parameter;
- render duplicate specialist entity-detail components;
- open specialist property/relationship drawers tied to those dead detail routes;
- retain page-local CSS for those unreachable detail components.

## Repository boundary

RDL-033 does **not** remove CFIHOS repositories merely because a retired page no longer imports them. Repositories may still be used by CIS, lifecycle, inspection, validation or other application capabilities and require separate usage proof before deletion.

RDL-033 also does not change canonical generic entity-detail semantics, release/version identity, relationship generation or search-index generation.

## Local gates

Required locally:

1. `npm run test:rdl-029`
2. `npm run test:rdl-030`
3. `npm run test:rdl-031`
4. `npm run test:rdl-032`
5. `npm run test:rdl-033`
6. `npm run test:regression`
7. `npm run build`
8. `git diff --check`
9. verify runtime search and relationship indexes are unchanged

Local Playwright is intentionally not run on the corporate-managed Mac. GitHub Actions Chromium remains the authoritative browser E2E and accessibility gate.

## Completion rule

RDL-033 is complete when RDL-033.2 passes the local deterministic/build gates and GitHub Chromium confirms that the retained browse/list surfaces, legacy compatibility redirects, canonical detail routes and accessibility remain green.
