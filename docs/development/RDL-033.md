# RDL-033 - Specialist Detail Code Retirement & Simplification

## Objective

Retire the duplicate CFIHOS specialist entity-detail implementations after RDL-032 made the release-aware generic entity detail the canonical runtime model.

RDL-033 is a non-functional simplification sprint. Existing browse/list entry points remain available, legacy detail URLs remain compatible, and all detail rendering continues through the canonical `/rdl/:sourceKey/:releaseKey/:entityType/:nativeIdentifier` architecture.

## RDL-033.1 - Browse-page retirement foundation

RDL-033.1 removes route-param-driven specialist detail logic from:

- Tag Classes
- Equipment Classes
- Document Types
- Data Dictionary / Properties
- Source Standards
- Disciplines
- Units of Measure

The pages remain browse/search surfaces. Selecting an entity still navigates to the existing legacy compatibility URL, which RDL-032 immediately redirects to the explicitly pinned CFIHOS 2.0 canonical detail route.

RDL-033.1 also simplifies `RdlScopedLegacyGuard` so it is a browse/scope guard only. The retired `detailParam`, route-parameter lookup and intermediate generic-detail card are removed.

## Preserved behavior

- `/classes/tag`, `/classes/equipment`, `/documents`, `/dictionary`, `/standards`, `/disciplines`, and `/units` remain browse routes.
- Search/filter behavior on those pages remains in place.
- The seven legacy detail URL families remain registered through `RdlLegacyEntityRedirect`.
- CFIHOS compatibility redirects remain explicitly pinned to `cfihos` / `cfihos-2.0`.
- Non-CFIHOS browse scope remains release-isolated and fail-closed.
- RDL-030, RDL-031 and RDL-032 contracts remain mandatory.

## Removed behavior

The browse-page modules no longer:

- read detail route parameters;
- load specialist detail repositories in response to a route parameter;
- render duplicate specialist entity-detail components;
- open specialist property/relationship drawers tied to those dead detail routes;
- maintain a second detail-selection lifecycle in parallel with the generic renderer.

## Deliberate boundary

RDL-033.1 does not remove CSS selectors that are now unused. CSS retirement is intentionally deferred until the TypeScript/route retirement is proven in GitHub Chromium. This keeps functional convergence separate from stylesheet cleanup.

It also does not remove CFIHOS repositories merely because a retired page no longer imports them. Repositories may still be used by CIS, lifecycle, inspection, validation or other application capabilities and require separate usage proof before deletion.

## Local gates

Required locally:

1. `npm run test:rdl-030`
2. `npm run test:rdl-031`
3. `npm run test:rdl-032`
4. `npm run test:rdl-033`
5. `npm run test:regression`
6. `npm run build`
7. `git diff --check`
8. verify runtime search and relationship indexes are unchanged

Local Playwright is intentionally not run on the corporate-managed Mac. GitHub Actions Chromium remains the authoritative browser E2E and accessibility gate.

## Follow-on

After RDL-033.1 is green in GitHub Chromium, RDL-033.2 may remove CSS and other artifacts proven to be unreachable after specialist detail retirement.
