# RDL-031 — Consistent Rich Navigation Across RDLs

## Objective

Make the canonical release-aware `/rdl/:sourceKey/:releaseKey/:entityType/:nativeIdentifier` route useful beyond Definition/Provenance by projecting source-authoritative relationships into a generic browser detail model.

## Scope

- deterministic static `public/rdl-relationship-index.json` generated from the same CFIHOS/CCUS/Water sources used by ingestion;
- exact source + release + package isolation;
- generic rich detail sections and `On this page` navigation;
- progressive disclosure: 5 visible initially when a relationship section exceeds 10 items;
- release-aware links for hierarchy, properties, related classes, documents, information requirements and source standards;
- existing specialist CFIHOS pages remain intact;
- no database migration.

## Validation

Local corporate-machine gate:

1. `npm run generate:rdl-search-index`
2. `npm run generate:rdl-relationship-index`
3. `npm run test:rdl-030`
4. `npm run test:rdl-031`
5. `npm run test:regression`
6. `npm run build`
7. `git diff --check`

Playwright is **not** a local corporate-machine gate. GitHub Actions Chromium remains the authoritative browser E2E/accessibility gate.


## RDL-031.5 corrective note

RDL-031.4 failed its installation contract on a phantom CFIHOS Equipment endpoint (`CFIHOS-30000880`). RDL-031.5 does not weaken the contract. It corrects the static relationship generator to mirror typed database endpoint semantics and adds generator-level endpoint-integrity validation.
