# RDL-035.4 — Specialist Browse Retirement

## Objective

Retire the seven obsolete CFIHOS specialist browse implementations after RDL-035.3 proved CFIHOS parity on the shared `RdlReleaseAwareBrowse` navigation model in GitHub Chromium.

## Scope

This increment removes only browse implementations and their browse-only stylesheets:

- Tag Classes
- Equipment Classes
- Document Types
- Data Dictionary / Properties
- Source Standards
- Disciplines
- Units of Measure

The legacy browse URLs remain unchanged. They now terminate directly at `RdlScopedLegacyGuard`, which delegates the seven primary entity families to `RdlReleaseAwareBrowse`. Legacy detail URLs continue to converge through `RdlLegacyEntityRedirect` to canonical release-aware entity detail.

## Explicit non-scope

CFIHOS repositories and models are **not** retired. They remain required by CIS derivation, CIS Builder/Preview, Assistant, Data Source diagnostics, Data Model, lifecycle and inspection capabilities. Specialized CFIHOS views such as Lifecycle Requirements and Data Model are also preserved.

## Guard design

`RdlScopedLegacyGuard` is intentionally changed only enough to allow shared browse routes to omit a child (`children?: ReactNode`). Its existing source/release fail-closed behavior remains intact to avoid unnecessary regression risk in earlier RDL-029/030/034 contracts.

## Deterministic acceptance

RDL-035.4 proves that:

1. all 14 specialist TSX/CSS artifacts are absent;
2. all seven primary browse URLs remain registered;
3. those routes directly select the shared release-aware guard without loading specialist pages;
4. legacy detail redirects remain canonical and explicitly pinned;
5. specialized Lifecycle/Data Model capabilities remain intact;
6. key CFIHOS repositories remain present;
7. `RdlReleaseAwareBrowse` remains source-neutral and hierarchy-safe;
8. search and relationship runtime index hashes are unchanged;
9. RDL-033, RDL-034, RDL-035, application regression and build gates remain green.

GitHub Actions Chromium remains the authoritative E2E/accessibility gate. Local Playwright is not required.
