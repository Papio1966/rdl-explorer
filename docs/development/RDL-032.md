# RDL-032 — Unified Entity Detail Parity and Legacy Convergence

## Objective

Converge RDL Explorer on one release-aware entity-detail architecture without losing capabilities already available in the CFIHOS specialist detail pages.

## RDL-032.1 — parity inspection

The inspection confirmed that RDL-031 established a release/package-isolated generic detail route and static relationship index, while the existing CFIHOS specialist pages still expose additional structured semantics: effective inherited properties, measurement units, controlled values, discipline/document context, reverse class usage and detailed Source Standard mappings.

## RDL-032.2 — parity foundation

This increment extends the static browser projection before any legacy-route ownership changes.

Delivered foundations:

- effective class properties calculated from explicit same-release hierarchy edges, with closest/direct assignments overriding inherited duplicates;
- Property → Unit of Measure projection from explicit workbook unit/dimension identifiers and explicit class-property unit references;
- Property → Controlled Value projection using explicit picklist identifiers without introducing synthetic controlled-list search entities;
- Controlled Value → Source Standard provenance;
- Source mapping evidence projected as class/property/standard relationships using explicit workbook identifiers;
- enriched Discipline ↔ Document Type relationship attributes for lifecycle/delivery context;
- richer Information Requirement relationship attributes where the source workbook supplies them;
- reverse projections for Used by Classes, Required by Classes, Document Types and Source Standard usage;
- contextual generic section labels for Tag and Equipment Classes;
- accessible progressive disclosure with `aria-expanded` and `aria-controls`;
- no arbitrary three-field truncation of relationship metadata.

## Release-safety rule

Every generated relationship must resolve both endpoints inside the exact `sourceKey + releaseKey + packageKey` represented in the committed search index. Generation fails closed if an endpoint is absent. No relationship is inferred across releases or packages.

## Search-index stability

RDL-032.2 does not change the search-index schema or generator. Controlled-list semantics are flattened to Property → Controlled Value relationships for the browser projection so the existing release identity/search baseline remains stable.

## Legacy convergence boundary

RDL-032.2 deliberately does **not** replace the specialist CFIHOS routes. The next increment can introduce a thin compatibility adapter only after the generic parity contract and GitHub Chromium E2E/accessibility gates are green.

## Validation

Local mandatory gates:

1. regenerate the relationship index;
2. RDL-030 release-isolation contract;
3. RDL-031 rich-navigation contract;
4. RDL-032 parity contract;
5. full deterministic regression suite;
6. production build;
7. `git diff --check`.

Playwright is not a local corporate-machine gate. GitHub Actions Chromium remains authoritative for browser E2E and accessibility.
